# Tchangy Studio 🏠

Un papa de quatre enfants qui bricole la maison connectée sur son temps libre.
Des outils pour **Home Assistant**, des applis familiales, et un jour un petit jeu mobile.
Tout est fait maison, sans pub, et codé en binôme avec Claude (l'IA d'Anthropic).

## Projets

| | Projet | |
|---|---|---|
| 🎓 | [**Révisions pour Home Assistant**](https://github.com/tchangy-studio/revisions-ha) | la tirelire, la récré et les bonus / malus des enfants dans Home Assistant |
| 📚 | **Révisions** | l'appli pour réviser en jouant, de la petite section au CM2 *(bientôt)* |
| 🌐 | **Domaines** | des adresses simples (`jellyfin.home`) gérées depuis Home Assistant *(bientôt)* |
